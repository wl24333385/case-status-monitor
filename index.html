Case Status Monitor

Automated USCIS Case Status Monitoring

A personal tool that automatically checks USCIS immigration case statuses using the official USCIS Torch API and sends real-time push notifications when any changes are detected.

Official API

Uses the USCIS Torch Case Status API with OAuth 2.0 authentication for reliable, authorized access to case data.

Automated Checks

Runs multiple times daily on a schedule with zero manual intervention required. No need to keep any device running.

Instant Alerts

Sends push notifications immediately when a case status changes, so you never miss an important update.

Privacy Policy

Case Status Monitor is a personal-use application. The following outlines how data is handled:

  • This application is used solely by its developer for personal immigration case monitoring.
  • No user data is collected from any third parties.
  • No data is sold, shared, or transferred to any third party for any reason.
  • The only data stored is USCIS case status information retrieved via the official API, kept in a private repository.
  • OAuth credentials are stored securely using GitHub encrypted secrets and are never exposed in code.
  • No cookies, tracking pixels, or analytics are used.
  • Data can be permanently deleted at any time by deleting the private repository.
  • In the event of a data breach, the developer will rotate all credentials immediately.
  • If the application is discontinued, all stored data will be permanently deleted.

Terms of Service

This application is a personal tool built for individual use. It is not a commercial product or service.

  • The application accesses only the developer's own USCIS case information.
  • No accounts are created for or offered to other users.
  • The application complies with the USCIS Torch API Terms of Use.
  • All API credentials are stored securely and not shared.
  • The developer may discontinue use at any time by removing the application and deleting all associated data.
