Liang Wu — Case Status Monitor

Automated USCIS Case Status Monitoring

A personal tool developed by Liang Wu that automatically checks USCIS immigration case statuses using the official USCIS Torch API and sends real-time push notifications when any changes are detected.

Official API

Uses the USCIS Torch Case Status API with OAuth 2.0 authentication for reliable, authorized access to case data.

Automated Checks

Runs multiple times daily on a schedule with zero manual intervention required. No need to keep any device running.

Instant Alerts

Sends push notifications immediately when a case status changes, so you never miss an important update.
